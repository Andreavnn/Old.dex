Repository cleanup workflow
---------------------------
This package adds .github/workflows/repository-cleanup.yml.
After it is uploaded:
1. Open the Old.dex repository on GitHub.
2. Open Actions.
3. Choose "Repository cleanup".
4. Choose "Run workflow" with apply_changes OFF first. This is a dry run.
5. Review the proposed file removals in the workflow log.
6. If they are correct, run it again with apply_changes ON to commit the cleanup.

The workflow is intentionally limited to old generated verification/upload archives
and preview artifacts at repository root. It does not remove src/, public/, tests/,
package files, README.md, CHANGELOG.md, or the current verification file.
