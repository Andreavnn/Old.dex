Old.dex v0.63 direct-source update

Upload the CONTENTS of this package to the root of Andreavnn/Old.dex on main,
replacing matching paths and adding new files/directories.

Do not upload it as a nested Old.dex-v0.63-DIRECT-SOURCE folder.

This update changes the core data resolver. After deployment, perform a hard refresh
(or fully close/reopen the installed PWA once) so the v0.63 service-worker cache is active.

The package updates the Repository cleanup workflow default so
ODX_V063_VERIFICATION.txt is treated as the current verification file.

Primary v0.63 data changes
--------------------------
- Old World Builder army JSON remains the structured roster source.
- OWB rules-index-export.json + rules-map.js additions/synonyms are now the canonical identity resolver.
- OWB indexed stats are preferred for unit and mount profiles.
- TOW page fetching is secondary detail enrichment rather than the primary identity guesser.
- Source parsing is resolver-aware so punctuation inside canonical names is preserved.
- Footer language choices now select OWB localized source fields for live roster/profile data.
- A whole-army resolver audit service is included for future completeness checks.
