For normal review:
  Use the deployed Old.dex URL.

When generated by `npm run build:review` or CI, preview.html is a standalone review artifact. It is not the application source.
All application changes belong in src/ and are then regenerated into the review preview.

Developer/Vite entry points:
  index.html          Normal application entry
  preview-vite.html   Vite-only development preview entry

Future release rule:
  Edit application -> test/build application -> generate standalone preview -> verify -> package.
  Never patch preview.html to implement application behavior.
