IMPORTANT SCOPE NOTE
Old World Builder normally opens the resolved TOW rule URL in its rule viewer. Old.dex renders native rule cards and weapon/profile tables, so it still reads the already-resolved canonical TOW page for detail content. The architectural change in 0.63 is that page scraping is no longer responsible for deciding what entity a source name represents.
